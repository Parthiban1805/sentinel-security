# Security policy

- Report suspected leaks or incidents to the incident owner: **parthi.s1805@gmail.com**.
- Never paste secrets into issues, PRs, chat or AI tools. Share a fingerprint and location instead.
- A leaked credential is revoked first, investigated second. Deleting it from the repo is not enough:
  it remains in Git history, forks and caches.
- See `docs/runbooks/credential-exposure.md`.
